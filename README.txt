วิธีติดตั้งและใช้งาน Tablet Mouse
---------------------------------

สิ่งที่ต้องมีในคอมพิวเตอร์:
1. โปรแกรม Python (โหลดได้ฟรีจาก https://www.python.org/downloads/ หรือ Microsoft Store)

วิธีติดตั้งครั้งแรก:
1. เปิด Command Prompt (พิมพ์ cmd ในช่องค้นหาของ Windows)
2. ก๊อปปี้คำสั่งด้านล่างนี้ไปวางแล้วกด Enter:
   pip install websockets pynput

   (ถ้าระบบฟ้องว่าหาคำสั่ง pip ไม่เจอ ให้ใช้คำสั่งนี้แทนครับ:)
   python -m pip install websockets pynput
3. รอจนมันโหลดและติดตั้งเสร็จ

วิธีเปิดใช้งาน:
1. เข้าไปในโฟลเดอร์ app
2. ดับเบิ้ลคลิกไฟล์ที่ชื่อว่า Start_Tablet_Mouse.bat
3. จะมีหน้าต่างสีดำเด้งขึ้นมา พร้อมบอก URL (เช่น http://192.168.x.x:8000)
4. เอาแท็บเล็ตต่อ Wi-Fi เดียวกัน หรือเสียบสาย USB แล้วเปิดแชร์เน็ต
5. เปิดเว็บเบราว์เซอร์ในแท็บเล็ต พิมพ์ URL นั้นลงไปก็ใช้งาน

(หมายเหตุ: ถ้าอยากได้ไอคอนสวยๆ ไว้ที่หน้า Desktop ให้คลิกขวาที่ไฟล์ Start_Tablet_Mouse.bat -> เลือก Send to -> Desktop (create shortcut)
